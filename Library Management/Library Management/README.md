# Library Management System

A Python-based Library Management System with a graphical user interface, MySQL database integration, and Gemini AI assistance.

This is my first and final high-school project, created as part of my Class 12 Computer Science project.

The user interface was made with help from my Discord friends reallytyler and cosin (final year engineering college).

## Features

- User Login
- Dashboard
- Book Management
- Student Management
- Issue Books
- Return Books
- View Records
- MySQL Database Integration
- Gemini AI Assistant
- Dark user interface
- Database connection testing

Library reports and stock checks are saved in the Modules folder. They are not buttons on the main screen.

## Technologies Used

- Python
- CustomTkinter (built on Tkinter)
- MySQL
- mysql-connector-python
- Requests
- Pillow
- Gemini API

## Requirements

Before running this project, install:

- Python 3
- MySQL Server 8
- Git (optional)
- Gemini API key (optional)
